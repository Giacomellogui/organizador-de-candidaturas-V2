📋 **Organizador de Candidaturas | HTML, CSS e TypeScript**

Aplicação web desenvolvida para facilitar o gerenciamento e acompanhamento de candidaturas a vagas de emprego, permitindo que usuários organizem suas oportunidades profissionais de forma prática e eficiente.

O projeto utiliza **HTML5, CSS3 e TypeScript**, com foco em uma interface intuitiva, organização de dados e boas práticas de desenvolvimento front-end.

🚀 **Principais funcionalidades:**
- Cadastro e gerenciamento de candidaturas.
- Organização de vagas por empresa, cargo e status.
- Acompanhamento das etapas dos processos seletivos.
- Edição e exclusão de candidaturas.
- Interface responsiva e de fácil utilização.

🛠️ **Tecnologias utilizadas:** HTML5 | CSS3 | TypeScript

🎯 **Objetivo:** Desenvolver uma solução simples e funcional para centralizar informações sobre processos seletivos, além de aprimorar conhecimentos em desenvolvimento web e TypeScript.
